# Baseline profile for Lampcord.
#
# A Compose client without an ART profile pays full class-loading and
# interpretation cost on every cold start, and the profile also gives R8 the
# real startup graph to optimise against.
#
# This hand-written profile covers the start-to-first-frame path: Application
# init, Koin graph construction, the gateway/HTTP stack, and the first
# composition. Regenerate with a Macrobenchmark run to get a full profile:
#
#   ./gradlew :androidApp:generateBaselineProfile
#
